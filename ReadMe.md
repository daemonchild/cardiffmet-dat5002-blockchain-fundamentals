### Section 3 – Blockchain Development (2000 words) (65%)
This task requires you to work in a team of three. You will be required to develop a DAPP by drawing from the skills and knowledge gained during the course of this module. As a team, agree on either of the following two use cases (Only develop one of the two) based on your interest.

**Task 3.1 (a) Design a blockchain based application that allows you to tokenise a real world asset, for
example real estate. The application should meet the following requirements (50%).**
- Allows the user to define an Asset.
- Tokenise the asset by creation of the native tokens representing a fractional share of the asset.
- Purchase, transfer and sell the asset.
- Allows to calculate how many assets have been created.
- Allows to calculate the owners of the assets and work out the top 10 beneficiaries.

**Task 3.1 (b) Design a generic decentralised blockchain based tender / contracting application. The
application should meet the following requirements (50%)**
- Allows a set of pre-registered users to setup tender requests for other addresses to bid on.
- Allows users to vote on the campaign.
- Only allow one bid per address.
- An address can revise their bid as many times as they wish, until the cut-off time.
- Assign the tender to the highest bidder once the bidding time is over.
